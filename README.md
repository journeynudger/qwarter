# qwarter

qwarter.com on Next.js + Vercel: synchronized.studio's design (layout, type, motion, scroll, cursor),
carrying Qwarter's own words, clients and pictures. Paper shaders included.

```
npm install
npm run dev        # http://localhost:3000
npm test           # content model + markup renderer
npm run build
```
